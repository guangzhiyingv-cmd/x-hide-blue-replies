# X 隐藏蓝 V 回复

在 X 的推文详情页隐藏蓝 V 回复，并在时间线和推文详情页的推文右上角添加关注、取消关注和屏蔽按钮。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开[脚本安装链接](https://raw.githubusercontent.com/guangzhiyingv-cmd/x-hide-blue-replies/main/x-hide-blue-replies.user.js)，点击安装，然后刷新 X。

## 使用

- 在 Tampermonkey 菜单里，可以开启「保留推主回复」或「保留已有回复的评论」。两个开关可独立使用，设置会自动保存。
- 圆形图标的提示会显示操作和账号。蓝色对勾表示已关注，点击即可取消关注。
- 点击屏蔽图标会立即发起屏蔽。脚本核对 X 弹窗里的账号后，会自动确认。

发现按钮错位或失效时，请在 [Issues](https://github.com/guangzhiyingv-cmd/x-hide-blue-replies/issues) 附上浏览器版本、X 界面语言和复现步骤。
